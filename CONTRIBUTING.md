# Contribution guidelines

APCF is a control shell: changes should improve real project compatibility, evidence quality, rule routing or safe delivery—not introduce a second copy of Canonical Rules.

Before opening a pull request, describe the observed problem, source version, expected/actual result, reproducible steps and a regression test. Keep project-private files, credentials, student/work records and real user data out of public issues and commits.

Run the repository's current lint and report/design checks; when modifying the framework itself, complete the applicable Full Gate in the real source environment. Changes that alter R01–R31, Writing, Style or Design require explicit authority and appropriate migration evidence. Optional UI is not automatically part of Core.

This repository's public availability does not by itself establish a contribution license or inbound rights grant. Applicable license terms are those in the actual release repository.
