# 1. 共享设计基线来源

本文件保存迁入共享基线时可复用的外部方法来源。来源用于解释设计规则的研究背景，不自动把外部设计系统的全部数值、组件或品牌语言升级为当前项目要求。

下列研究和访问描述保留源包的研究背景，不代表本次集成重新检索了所有页面；历史访问状态和原样板测量不能直接作为当前项目证据

原包中的 S09 具体指向用户对话、旧文件和 Library 材料，不能作为跨项目共享的固定私有来源；这里把 S09 转化为“当前项目证据层”的通用引用语义，具体项目仍必须读取自己的用户反馈、已认可界面和项目事实。S21 与 S22 是原包本次模板采用和旧 APCF v0.2.2 快照，不作为长期共享方法来源。

- <a id="s09"></a>**S09｜当前项目证据层**：当前用户明确要求、项目已认可界面／截图、现有项目设计资产和实际运行事实。共享 D 规则可以引用这一证据层，但不能把源包中的私有对话、Library 文件或历史项目内容自动带入其他项目。

- <a id="s01"></a>**S01｜Apple HIG**：[Menus](https://developer.apple.com/design/human-interface-guidelines/menus)、[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。采用对象相关菜单、分组、命名、图标一致性、主内容空间；不复制玻璃材质或平台外观。Apple 页面 JS 加载受限时使用其被检索到的官方文本。
- <a id="s02"></a>**S02｜Microsoft Fluent 2**：[Layout](https://fluent2.microsoft.design/layout)、[Typography](https://fluent2.microsoft.design/typography)、[Tooltip](https://fluent2.microsoft.design/components/web/react/core/tooltip/usage/)。采用接近性、4px 基础档位及光学例外、角色对齐、按需提示、内容区域的自适应重排；不把它的所有数值等同用户偏好。
- <a id="s03"></a>**S03｜IBM Carbon**：[Spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview)、[Spacing code](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/code)。采用共享 token、组件内外的空间尺度；不强行引入整套 Carbon React。
- <a id="s04"></a>**S04｜Adobe Spectrum**：[Platform scale](https://spectrum.adobe.com/page/platform-scale/)。采用布局占位区和命中区、鼠标与触摸尺度的区分。此页检索缓存可读，但本轮直接打开返回 404；作为历史方法参考，不作当前组件版本或固定比例依据。
- <a id="s05"></a>**S05｜Nielsen Norman Group**：[10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)。采用状态可见、与用户概念匹配、一致性、识别优于记忆、错误预防、控制与恢复；这是设计审查方法，不是满意度预测模型。
- <a id="s06"></a>**S06｜W3C/WAI**：[Tree View Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/)、[Menu Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/)、[Dialog Modal Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)、[Content on Hover or Focus](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)、[Dragging Movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)、[Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)、[Non-text Contrast](https://www.w3.org/WAI/WCAG22/understanding/non-text-contrast.html)、[Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)。用于角色、键盘、非拖动替代、可见性和重排；局部检查不冒充整站 WCAG 符合性评估。
- <a id="s07"></a>**S07｜开源组件实现参照**：[React Arborist](https://github.com/jameskerr/react-arborist)、[Radix Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu)、[Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog)、[react-resizable-panels](https://github.com/bvaughn/react-resizable-panels)。用于比较职责与交互合同；本包不包含这些运行依赖，也没有它们自带完整业务回收站的承诺。
- <a id="s08"></a>**S08｜VS Code 官方**：[User interface](https://code.visualstudio.com/docs/editing/getting-started/userinterface)、[Custom layout](https://code.visualstudio.com/docs/configure/custom-layout)。外壳、主副侧栏与视图迁移参照。用户提供的视觉参考属于当前项目证据层，不作为共享的私有对话来源，也不代表未公开的设计规范。
- <a id="s10"></a>**S10｜WAI / Fluent 下拉模式**：[Select-only Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/)、[Fluent Dropdown](https://fluent2.microsoft.design/components/web/react/core/dropdown/usage)、[Fluent Select](https://fluent2.microsoft.design/components/web/react/core/select/usage)。用于区分原生 select、可控外观的下拉和命令菜单，以及键盘探索／提交。当前实现原创；APG 例子不是生产认证。本样板外部指针点击取消未提交探索；正式接入需按产品合同和辅助技术实测校准，不声称逐字等同 APG 示例。
- <a id="s11"></a>**S11｜MDN Web Storage**：[Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)。同步操作会阻塞当前 JS 执行；用于解释合并写入的动机，不把内存夹具冒充真实磁盘性能。
- <a id="s12"></a>**S12｜web.dev 性能**：[Avoid layout thrashing](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing)、[Optimize INP](https://web.dev/articles/optimize-inp)。用于减少不必要的 DOM 重建、批处理布局工作以及区分实验室耗时与现场指标；并非已实现或已认证全套指标。
- <a id="s13"></a>**S13｜Apple Searching / Focus / Outline**：[Searching](https://developer.apple.com/design/human-interface-guidelines/searching)、[Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection/)、[Outline views](https://developer.apple.com/design/human-interface-guidelines/outline-views)。读取官方检索文本。采用全局入口、局部范围、焦点与激活区分、长层级名称可读；不接入Spotlight、不采用tvOS放大动画、不宣称复刻原生平台焦点系统。
- <a id="s14"></a>**S14｜Fluent微布局与内容语义**：[Layout](https://fluent2.microsoft.design/layout)、[Toolbar](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage/)、[Label](https://fluent2.microsoft.design/components/web/react/core/label/usage)、[Menu](https://fluent2.microsoft.design/components/web/react/core/menu/usage)、[Tooltip](https://fluent2.microsoft.design/components/web/react/core/tooltip/usage/)、[Divider](https://fluent2.microsoft.design/components/web/react/core/divider/usage)。Layout直接正文，其余按官方正文或索引文本。采用组件内／组合／页面空间区分、图标居中／文字对齐、标签非placeholder、按频率分组及语义快捷键。未把某公司的divider最小间距或菜单最大宽度设为本项目全局硬门槛。
- <a id="s15"></a>**S15｜IBM Carbon Search**：[Search accessibility](https://www.carbondesignsystem.com/building-blocks/core/components/search/accessibility)。直接读取官方正文。采用清除搜索及键盘恢复；本实现的Esc行为按弹层作用域区分，不笼统规定所有搜索框Esc都做同一件事。搜索结果提示与输入保持分离。
- <a id="s16"></a>**S16｜WAI交互合同**：[Toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/)、[Combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)。直接正文。用来核对成组导航、焦点与值分离、键盘提交／取消。当前工作台沿用既有原生按钮与活动栏roving规则，没有把每个容器伪装成已完整实现的ARIA toolbar；正式接入新toolbar时才应用其完整键盘合同。
- <a id="s17"></a>**S17｜WAI指针和可见焦点**：[Pointer Cancellation](https://www.w3.org/WAI/WCAG22/Understanding/pointer-cancellation.html)、[Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[Focus Not Obscured Minimum](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)。直接正文。采用可取消点击、命中区与例外、焦点不被遮蔽。局部自动检查不等于完整符合性或辅助技术认证。
- <a id="s18"></a>**S18｜Google/web.dev响应机制**：[Optimize INP](https://web.dev/articles/optimize-inp)、[Understanding INP](https://web.dev/codelabs/understanding-inp)、[Avoid layout thrashing](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing)。直接正文。用于拆分等待／执行／呈现、减少重复DOM与读写交叉、识别rAF仍在绘制之前。INP是页面交互质量指标，本次点击实验不能冒充真实用户第75百分位达标。
- <a id="s19"></a>**S19｜MDN测量边界**：[PerformanceEventTiming](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceEventTiming)、[interactionId](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceEventTiming/interactionId)、[Scheduler.yield](https://developer.mozilla.org/en-US/docs/Web/API/Scheduler/yield)。前两者正文／官方检索，yield为候选比较。Event Timing须考虑16ms最小报告阈值、8ms取整和同一交互多事件；当前运行代码没有强制依赖scheduler.yield，也没有声称所有浏览器支持。
- <a id="s20"></a>**S20｜NN/g感知响应**：[Response Times: The 3 Important Limits](https://www.nngroup.com/articles/response-times-3-important-limits/)。直接正文。采用“快速反馈与任务完成耗时不同”的审查视角；其时间尺度不是设备性能承诺，也不是给全部任务编造等待动画的理由。
