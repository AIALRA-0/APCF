# 1. 共享界面与体验设计规则

本文件是 APCF 共享设计基线中 D01–D16 的唯一规则正文。D 规则用于界面、交互、响应、稳定性与设计验收，不占用 R01–R31 的框架规则编号。

这些规则从 `AIALRA Workbench Template v2.3.1` 的 `DESIGN.md` 迁入；D01–D16 的编号、义务结构、验证结构与正反例语义保持来源内容；仅对少数绑定旧 Workbench 实现、固定 Profile 数值或旧 APCF 上下文的句子做职责适配，全部改动列在 `PROVENANCE.md`。分类只由 `design/INDEX.md` 负责路由，不把 D 规则物理拆成多个可独立漂移的正文。

<a id="d01"></a>
## D01 · 按主任务组织空间，不把工作台做成说明海报


### 原则

- <a id="d01-p01"></a>**D01-P01**：无关说明与装饰会抢占主任务空间，因此外壳负责导航、对象与状态，正文只承载内容。

### 触发

- <a id="d01-t01"></a>**D01-T01**：创建页面、加入工具、迁移已有界面。

### 必须

- <a id="d01-m01"></a>**D01-M01**：先确定文档／列表／画布／表单角色；
- <a id="d01-m02"></a>**D01-M02**：保留左导航、主内容、右检查器的职责；
- <a id="d01-m03"></a>**D01-M03**：两侧可收起；
- <a id="d01-m04"></a>**D01-M04**：首页不堆“为什么优秀”、技术路线、虚假完成指标。
- <a id="d01-m05"></a>**D01-M05**：主导航由单一 activity 状态驱动：文件、搜索、回收站、组件参照只允许一个当前页面。
- <a id="d01-m06"></a>**D01-M06**：设置、帮助是临时操作，不加入主导航选中集合；
- <a id="d01-m07"></a>**D01-M07**：左右侧栏显示按钮属于独立布局控制，不与导航混算。
- <a id="d01-m08"></a>**D01-M08**：按钮、命令面板和文件打开必须走同一状态更新路径。
- <a id="d01-m09"></a>**D01-M09**：全局搜索“文件与命令”和局部“过滤文件／列表筛选”分别标明范围；
- <a id="d01-m10"></a>**D01-M10**：搜索按钮缩成图标时仍有可访问名称、快捷键和同一入口。
- <a id="d01-m11"></a>**D01-M11**：主导航的当前项与键盘焦点不同，移动焦点不提前激活页面；
- <a id="d01-m12"></a>**D01-M12**：重复点击当前文件保留编辑器、草稿与光标。

### 验证

- <a id="d01-v01"></a>**D01-V01**：打开默认页能直接选对象、读或编辑内容；
- <a id="d01-v02"></a>**D01-V02**：正文中不存在旧版说明卡片；
- <a id="d01-v03"></a>**D01-V03**：各视图可从同一外壳进入。

### 例外

- <a id="d01-e01"></a>**D01-E01**：介绍页可以讲解产品；
- <a id="d01-e02"></a>**D01-E02**：不能把介绍页的设计自动作为工具型页面默认。

### 错误示例

- <a id="d01-b01"></a>**D01-B01**：用“支持 CRUD”卡片代替可操作文件树。

### 正确示例

- <a id="d01-g01"></a>**D01-G01**：文件树承担对象管理，中央呈现文档，右侧只显示当前选择的属性。

### 依据

- <a id="d01-s01"></a>**D01-S01**：Apple Layout、NN/g 最小化与可识别性原则；见 S01、S05。
<a id="d02"></a>
## D02 · 用中性色建立结构，语义色只承担必要含义


### 原则

- <a id="d02-p01"></a>**D02-P01**：每个区域独立加色会分散注意，结构用中性色，状态与数据采用有意义且一致的颜色。

### 触发

- <a id="d02-t01"></a>**D02-T01**：主题、选择态、图标、提示、图表变化。

### 必须

- <a id="d02-m01"></a>**D02-M01**：默认页面使用中性背景、文字、边界和选择态；
- <a id="d02-m02"></a>**D02-M02**：删除／错误有明确语义；
- <a id="d02-m03"></a>**D02-M03**：正常页面不铺红黄绿徽章；
- <a id="d02-m04"></a>**D02-M04**：提供明暗两套角色映射；
- <a id="d02-m05"></a>**D02-M05**：状态不只靠颜色。
- <a id="d02-m06"></a>**D02-M06**：hover／pressed／current等即时角色不增加颜色缓变；
- <a id="d02-m07"></a>**D02-M07**：主题切换时前景和背景须同步到达目标角色，不能只检查动画结束后的静态对比。
- <a id="d02-m08"></a>**D02-M08**：开关滑块等有空间意义的运动不因此被一概禁止。

### 验证

- <a id="d02-v01"></a>**D02-V01**：默认文档、文件树和检查器无装饰色块；
- <a id="d02-v02"></a>**D02-V02**：组件参照中的成功、警告、错误同时有图标与文字；
- <a id="d02-v03"></a>**D02-V03**：明暗主题均检查。

### 例外

- <a id="d02-e01"></a>**D02-E01**：地图、数据系列、媒体及已认可品牌元素可保留用色；
- <a id="d02-e02"></a>**D02-E02**：不设全局灰度滤镜。

### 错误示例

- <a id="d02-b01"></a>**D02-B01**：把成功绿、错误红强制变黑，或给每一块卡片配一种强调色。

### 正确示例

- <a id="d02-g01"></a>**D02-G01**：默认检查器保持灰色，危险操作才使用错误色。

### 依据

- <a id="d02-s01"></a>**D02-S01**：用户对黑白主体与语义色的明确区分；WCAG 非单一颜色信息要求，S06。
<a id="d03"></a>
## D03 · 区分内部间距、组间距与独立区域间距


### 原则

- <a id="d03-p01"></a>**D03-P01**：接近性表达关系；全部贴合会混组，全部拉开会断组，所以间距按角色分配。

### 触发

- <a id="d03-t01"></a>**D03-T01**：新增组件、排列工具栏、修改侧栏和内容区。

### 必须

- <a id="d03-m01"></a>**D03-M01**：使用统一间距档位；
- <a id="d03-m02"></a>**D03-M02**：父容器控制兄弟间隔，组件控制内部留白；
- <a id="d03-m03"></a>**D03-M03**：同组紧凑，不同组清楚分隔；
- <a id="d03-m04"></a>**D03-M04**：不得用负外边距或偶然偏移遮掩结构问题。
- <a id="d03-m05"></a>**D03-M05**：父级分配可用空间，不能只校验视口是否溢出；
- <a id="d03-m06"></a>**D03-M06**：侧栏缩窄后也要检查中心区实际宽度。
- <a id="d03-m07"></a>**D03-M07**：短面板按内容排布，通知条避开当前固定工具栏和内容状态栏。
- <a id="d03-m08"></a>**D03-M08**：默认独立面板间距采用当前参数表规定值；
- <a id="d03-m09"></a>**D03-M09**：舒适密度的控件、组间留白与文档内边距同步调整，不把全部小间距一起放大。
- <a id="d03-m10"></a>**D03-M10**：布局仍保留主区空间预算；
- <a id="d03-m11"></a>**D03-M11**：窄屏使用抽屉。
- <a id="d03-m12"></a>**D03-M12**：分别度量图标可见尺寸、命中框、框内留白、相邻命中框净距及组边缘留白。
- <a id="d03-m13"></a>**D03-M13**：面板 gap 放大不能冒充控件内部已变宽；
- <a id="d03-m14"></a>**D03-M14**：导航、顶部搜索、局部筛选各有尺寸角色。
- <a id="d03-m15"></a>**D03-M15**：扩大常用入口时同步检查中心区预算及短高度可达性，不把所有间距等比例扩大。

### 验证

- <a id="d03-v01"></a>**D03-V01**：默认三个独立面板间距由同一 `gap` 驱动；
- <a id="d03-v02"></a>**D03-V02**：标题与边界不挤压；
- <a id="d03-v03"></a>**D03-V03**：宽高随内容合理变化，不自动把短说明拉成长卡片。

### 例外

- <a id="d03-e01"></a>**D03-E01**：表格行、分段控件、标签条等连续整体允许共享边界。
- <a id="d03-e02"></a>**D03-E02**：图标光学补偿不必机械坚持 4 的倍数，但要限于组件内部。

### 错误示例

- <a id="d03-b01"></a>**D03-B01**：侧栏使用自动伸展网格，把两行说明拉成 300px 高的空卡片。

### 正确示例

- <a id="d03-g01"></a>**D03-G01**：纵向文档流排属性，组与组用间距或一条必要分隔线区分。

### 依据

- <a id="d03-s01"></a>**D03-S01**：Fluent proximity／spacing、Carbon spacing tokens，S02、S03。
<a id="d04"></a>
## D04 · 同角色对齐，同角色同规格


### 原则

- <a id="d04-p01"></a>**D04-P01**：一致性来自角色和参考线，而不是把所有对象强行设成一样宽高。

### 触发

- <a id="d04-t01"></a>**D04-T01**：按钮、树行、表单、菜单、列表和工具栏变化。

### 必须

- <a id="d04-m01"></a>**D04-M01**：同角色按钮统一高度、内边距与图标；
- <a id="d04-m02"></a>**D04-M02**：输入与标签共享左边缘；
- <a id="d04-m03"></a>**D04-M03**：菜单的图标、名称、快捷键各有对齐列；
- <a id="d04-m04"></a>**D04-M04**：文件树按层级缩进；
- <a id="d04-m05"></a>**D04-M05**：表格数字按数据需要对齐。
- <a id="d04-m06"></a>**D04-M06**：紧凑工具按钮共用 compact-control 角色，输入字段共享整列左、右边缘；
- <a id="d04-m07"></a>**D04-M07**：文字、图标、快捷键各自对齐。
- <a id="d04-m08"></a>**D04-M08**：树名称不得因层级缩进归零；
- <a id="d04-m09"></a>**D04-M09**：深层结构允许树容器内水平滚动，键盘定位时必须将名称本身带入可视范围，不能只让宽整行获得焦点而文字仍在屏幕外；
- <a id="d04-m10"></a>**D04-M10**：不能引发整页横向溢出。
- <a id="d04-m11"></a>**D04-M11**：同角色面板底部状态栏必须共用同一 footer-height 角色；精确值来自当前项目或已采用 Profile，不在共享规则中固定；
- <a id="d04-m12"></a>**D04-M12**：检查的是顶部边线、底部与文字基线，而不只检查面板外框。
- <a id="d04-m13"></a>**D04-M13**：选项列表与命令菜单共用 popup-surface、choice-row 的背景、边框、圆角、行高、文字和内边距，角色语义不混用。
- <a id="d04-m14"></a>**D04-M14**：活动栏图标在各自命中框内居中，多个框采用一致的中心线与净距；
- <a id="d04-m15"></a>**D04-M15**：搜索图标、输入文字、清除操作和快捷键按稳定槽位排列。
- <a id="d04-m16"></a>**D04-M16**：聚焦／按下只改变颜色或轮廓，不通过缩放位移制造按钮跳动。
- <a id="d04-m17"></a>**D04-M17**：同角色面板的 footer-height 共用当前项目或已采用 Profile 的同一值，不因无关顶部空间调整而漂移。

### 验证

- <a id="d04-v01"></a>**D04-V01**：三面板顶部与底部对齐；
- <a id="d04-v02"></a>**D04-V02**：同组工具按钮边界等高；
- <a id="d04-v03"></a>**D04-V03**：长名称不会推出末端操作；
- <a id="d04-v04"></a>**D04-V04**：树图标和文字基线稳定。

### 例外

- <a id="d04-e01"></a>**D04-E01**：图标按钮可等宽，文字按钮按名称扩展，不能为了等宽制造巨大空按钮。

### 错误示例

- <a id="d04-b01"></a>**D04-B01**：为了统一，把正文、树行、数值、按钮全部居中。

### 正确示例

- <a id="d04-g01"></a>**D04-G01**：图标在命中区居中，内容文字左对齐，末端操作位置固定。

### 依据

- <a id="d04-s01"></a>**D04-S01**：Fluent alignment 与 Adobe placement／hit area 的区分，S02、S04。
<a id="d05"></a>
## D05 · 文字按语义分层，不靠小字挤满界面


### 原则

- <a id="d05-p01"></a>**D05-P01**：控制界面的密度与阅读正文的舒适度不同，必须采用不同文字角色。

### 触发

- <a id="d05-t01"></a>**D05-T01**：任何文字、标签、表格或文档内容变化。

### 必须

- <a id="d05-m01"></a>**D05-M01**：使用系统无衬线字体栈并包含中文回退；
- <a id="d05-m02"></a>**D05-M02**：正文、标题、辅助文字分角色；
- <a id="d05-m03"></a>**D05-M03**：正文不套整页等宽字体；
- <a id="d05-m04"></a>**D05-M04**：重要信息不使用极小或极浅灰文字；
- <a id="d05-m05"></a>**D05-M05**：长标题可换行，树和标签可省略并保留完整名称入口。
- <a id="d05-m06"></a>**D05-M06**：长树名称和标签页保留完整名称提示；
- <a id="d05-m07"></a>**D05-M07**：阅读正文不因中心区变窄而缩成辅助字号。
- <a id="d05-m08"></a>**D05-M08**：列表标题和操作按主内容容器宽度重排，而非只看设备宽度。
- <a id="d05-m09"></a>**D05-M09**：表单标签不由 placeholder 替代；
- <a id="d05-m10"></a>**D05-M10**：可选帮助不挤占主要字段。
- <a id="d05-m11"></a>**D05-M11**：全局搜索结果显示名称与路径，名称是主信息，路径是辨别同名项的辅助信息。
- <a id="d05-m12"></a>**D05-M12**：长字段标签允许换行；
- <a id="d05-m13"></a>**D05-M13**：文件名省略必须能取得全名，不把一切长文字直接裁掉。

### 验证

- <a id="d05-v01"></a>**D05-V01**：实际浏览器确认中文字体回退；
- <a id="d05-v02"></a>**D05-V02**：长中文、连续长串、标题、列表、缩小窗口不溢出；
- <a id="d05-v03"></a>**D05-V03**：不得把未安装字体当成已经渲染。

### 例外

- <a id="d05-e01"></a>**D05-E01**：代码编辑区使用等宽字体；
- <a id="d05-e02"></a>**D05-E02**：工具栏允许比阅读正文紧凑。
- <a id="d05-e03"></a>**D05-E03**：候选字号不是测得的个人最优值。

### 错误示例

- <a id="d05-b01"></a>**D05-B01**：声明 Inter，但实际中文回退不受控，再把全站缩成 11px。

### 正确示例

- <a id="d05-g01"></a>**D05-G01**：使用同一中文无衬线回退链，文档正文与 UI 辅助信息分别定义。

### 依据

- <a id="d05-s01"></a>**D05-S01**：Fluent typography、用户对字体与密度的反馈，S02。
<a id="d06"></a>
## D06 · 图标、标签与辅助提示共同表达操作


### 原则

- <a id="d06-p01"></a>**D06-P01**：图标能压缩常见动作，但没有标签或可访问名称会把识别负担转给用户。

### 触发

- <a id="d06-t01"></a>**D06-T01**：替换文字按钮、引入图标和 Tooltip。

### 必须

- <a id="d06-m01"></a>**D06-M01**：同一图标集合、画布、线宽与颜色规则；
- <a id="d06-m02"></a>**D06-M02**：不混用 emoji、字符符号和多套图标；
- <a id="d06-m03"></a>**D06-M03**：图标按钮有可访问名称；
- <a id="d06-m04"></a>**D06-M04**：简短提示支持 hover 与键盘焦点；
- <a id="d06-m05"></a>**D06-M05**：Esc 可关闭；
- <a id="d06-m06"></a>**D06-M06**：字段名称、危险操作、菜单条目保留文字。
- <a id="d06-m07"></a>**D06-M07**：自定义 Tooltip 在指针移入其文本后仍可读取，支持 Escape 单独关闭；
- <a id="d06-m08"></a>**D06-M08**：有模态框时进入同一顶层。
- <a id="d06-m09"></a>**D06-M09**：不能为了减少文字而删除可访问名称或必要菜单标签。
- <a id="d06-m10"></a>**D06-M10**：同一对象不同时设置浏览器 title 和同义自绘 Tooltip，避免叠加提示与不同延时。
- <a id="d06-m11"></a>**D06-M11**：自绘选择弹层打开时不再冒出底层控件 Tooltip。
- <a id="d06-m12"></a>**D06-M12**：提示仅解释动作，不承担保存失败、表单错误或不可缺少的内容；
- <a id="d06-m13"></a>**D06-M13**：触控不依赖悬停才能操作。

### 验证

- <a id="d06-v01"></a>**D06-V01**：图标均来自 `src/icons.js`；
- <a id="d06-v02"></a>**D06-V02**：可见图标按钮有非空名称；
- <a id="d06-v03"></a>**D06-V03**：悬停／聚焦能解释行为，移开或 Esc 后消失；
- <a id="d06-v04"></a>**D06-V04**：触屏仍可通过菜单文字理解。

### 例外

- <a id="d06-e01"></a>**D06-E01**：正文媒体可以有其他视觉风格；
- <a id="d06-e02"></a>**D06-E02**：不能因此改变工具图标。
- <a id="d06-e03"></a>**D06-E03**：重要内容不能只放在 Tooltip。

### 错误示例

- <a id="d06-b01"></a>**D06-B01**：文件夹用 emoji，删除用乱码字符，迁移又用另一套填充图标。

### 正确示例

- <a id="d06-g01"></a>**D06-G01**：相同线性 SVG 图标，图标与菜单标签共用同一动作。

### 依据

## D10 · 反馈必须真实，输入和恢复路径必须保留


### 原则

- <a id="d10-p01"></a>**D10-P01**：看得到反馈才能知道操作发生了什么；假成功与永久加载会破坏可控性。

- <a id="d10-m16"></a>**D10-M16**：局部筛选提供清除入口；
- <a id="d10-m17"></a>**D10-M17**：非空查询上 Esc 先清除并保留输入焦点，再次 Esc 才交由所属浮层处理。
- <a id="d10-m18"></a>**D10-M18**：全局命令面板有独立清除与关闭；
- <a id="d10-m19"></a>**D10-M19**：Esc 沿模态合同退出。
- <a id="d10-m20"></a>**D10-M20**：组合输入中的中间拼音不反复过滤／抢选；
- <a id="d10-m21"></a>**D10-M21**：提交后再过滤，真实系统输入法仍单独验收。

## D11 · 菜单、提示、对话框遵守同一焦点与层级合同


### 原则

- <a id="d11-m02"></a>**D11-M02**：抽屉内菜单进入同一顶层；

- <a id="d11-m12"></a>**D11-M12**：弹层附属于当前模态顶层，靠边翻转或限制高度。
- <a id="d11-m13"></a>**D11-M13**：模态提交防止关闭后的旧表单再次执行；

- <a id="d11-m15"></a>**D11-M15**：对话框构建、打开与增强完成后确定性聚焦当前可见字段，不用固定20ms等延迟猜测界面何时可用。
- <a id="d11-m16"></a>**D11-M16**：名称输入、设置当前分类、危险确认各自选择适用初始焦点；
- <a id="d11-m17"></a>**D11-M17**：焦点副作用不能从旧对话框迟到。
- <a id="d11-m18"></a>**D11-M18**：控件可立即呈现按下反馈，但导航／删除等仍在可取消的 click/up 激活，不为了抢响应改成 pointerdown 提交。

### 验证

- <a id="d11-v01"></a>**D11-V01**：菜单上下键、Home／End、Esc；
- <a id="d11-v02"></a>**D11-V02**：对话框 Tab 循环、取消与返回；
- <a id="d11-v03"></a>**D11-V03**：抽屉内菜单可点；
- <a id="d11-v04"></a>**D11-V04**：点击外部不会误执行背景动作。

### 例外

- <a id="d11-e02"></a>**D11-E02**：需要交互的帮助改用 Popover 或 Dialog。

### 原则

## D14 · 先复用共享实现，再修最小共同根因


### 原则

- <a id="d14-p01"></a>**D14-P01**：每页一份样式和行为会逐渐漂移，改公共来源才能减少重复提醒。

### 触发

- <a id="d14-t01"></a>**D14-T01**：创建同类组件、多处出现同一问题、引入外部组件库。

### 必须

- <a id="d14-m01"></a>**D14-M01**：同角色入口调用同一动作；
- <a id="d14-m02"></a>**D14-M02**：参数引用同一来源；
- <a id="d14-m03"></a>**D14-M03**：组件样板使用实际组件；
- <a id="d14-m04"></a>**D14-M04**：优先当前项目的成熟实现；
- <a id="d14-m05"></a>**D14-M05**：引入组件前核对许可、维护、状态、可访问性与适配范围，不为“像 IDE”迁移整个系统。
- <a id="d14-m06"></a>**D14-M06**：布局、焦点、菜单定位和模型各修共同来源；
- <a id="d14-m07"></a>**D14-M07**：右键、行末按钮、键盘和坐标输入共享动作。
- <a id="d14-m08"></a>**D14-M08**：组件参照退出后必须回到当前文件内容，不能只改变活动栏高亮。
- <a id="d14-m09"></a>**D14-M09**：关闭活动标签时主内容、文件树选择和检查器要同步。
- <a id="d14-m10"></a>**D14-M10**：优化输入热路径：输入立即更新内存与脏标记，不重建整个标签栏；

- <a id="d14-m12"></a>**D14-M12**：保存、导出和退出相关事件主动提交待写状态。
- <a id="d14-m13"></a>**D14-M13**：树索引按数据数组引用缓存，筛选、分栏拖动、画布平移等高频工作按帧合并；
- <a id="d14-m14"></a>**D14-M14**：缩放平移复用节点 DOM。
- <a id="d14-m15"></a>**D14-M15**：所有入口仍使用同一数据模型，不能为性能绕过验证。
- <a id="d14-m16"></a>**D14-M16**：树结构／展开状态／查询未变时，仅更新旧、新选中行和焦点，不重建整树；
- <a id="d14-m17"></a>**D14-M17**：结构修改后必须失效缓存。
- <a id="d14-m18"></a>**D14-M18**：文件路径索引随节点数组版本更新，命令箭头只更换活动结果，不重建列表。
- <a id="d14-m19"></a>**D14-M19**：不无故把现有面板反复append到同一父节点；
- <a id="d14-m20"></a>**D14-M20**：日期格式器复用。
- <a id="d14-m21"></a>**D14-M21**：界面状态立即更新，非关键快照在短延时后合并；
- <a id="d14-m22"></a>**D14-M22**：保存／导出／离开相关路径仍强制提交。

### 验证

- <a id="d14-v01"></a>**D14-V01**：右键、按钮、快捷键调用相同模型；
- <a id="d14-v02"></a>**D14-V02**：改一个 token 或组件影响所有适用位置；
- <a id="d14-v03"></a>**D14-V03**：工作区配置可导出 HTML 和 Agent 配置说明。

### 例外

- <a id="d14-e01"></a>**D14-E01**：本离线样板是无依赖实现，没有把 React Arborist、Radix、Theia 或其他第三方框架打包进来；
- <a id="d14-e02"></a>**D14-E02**：这些只作为生产接入候选，不作已集成声明。

### 错误示例

- <a id="d14-b01"></a>**D14-B01**：用文档宣布采用成熟树库，实际页面仍是手写静态 div。

### 正确示例

### 依据

## D15 · 用匹配的实际检查证明，不用总分遮盖失败


### 原则

- <a id="d15-p01"></a>**D15-P01**：构建成功不证明界面可用，截图存在不证明已看过，自动测试不证明用户满意。

### 必须

- <a id="d15-m01"></a>**D15-M01**：记录当前构建哈希、环境、输入、操作、预期、实测和证据；
- <a id="d15-m02"></a>**D15-M02**：分别记录视觉、交互、存储与范围外项；
- <a id="d15-m03"></a>**D15-M03**：重要失败增加回归；
- <a id="d15-m04"></a>**D15-M04**：不删除失败用例以变绿；
- <a id="d15-m05"></a>**D15-M05**：不直接把新截图设为认可样板。
- <a id="d15-m06"></a>**D15-M06**：先在旧构建冻结可复现缺陷，再在最终同一构建复验；
- <a id="d15-m07"></a>**D15-M07**：未复现的假设保留“本输入未复现”，不冒充修好缺陷。
- <a id="d15-m08"></a>**D15-M08**：截图人工检查与自动几何检查互补；
- <a id="d15-m09"></a>**D15-M09**：把新发现的碰撞写入回归，不只改截图。

- <a id="d15-m11"></a>**D15-M11**：优先核对写入次数、DOM 重建次数与最终数据，不把合成输入耗时当真实打字延迟或现场 INP。
- <a id="d15-m12"></a>**D15-M12**：必须补测存储配额失败、连续输入最长等待、快速保存、旧异步请求、重复提交以及反复开关浮层；
- <a id="d15-m13"></a>**D15-M13**：未测跨进程或真实磁盘持久性保持未执行。
- <a id="d15-m14"></a>**D15-M14**：点击拆为输入等待、事件处理、呈现等待三个阶段。
- <a id="d15-m15"></a>**D15-M15**：同步处理耗时、rAF后任务的帧机会代理、Event Timing条目分别标注，不称为同一个指标。
- <a id="d15-m16"></a>**D15-M16**：PerformanceEventTiming最小阈值与时间取整会漏记很快的事件，没有条目不能写零延迟。
- <a id="d15-m17"></a>**D15-M17**：比较必须注明版本、数据量、DOM规模、存储夹具、样本数与运行顺序；
- <a id="d15-m18"></a>**D15-M18**：用户主观慢尚未在其设备取样时，不声称已证明唯一根因。

### 验证

- <a id="d15-v01"></a>**D15-V01**：`TEST.md` 可反查具体检查与 `browser-results.json`；
- <a id="d15-v02"></a>**D15-V02**：未执行项明示；
- <a id="d15-v03"></a>**D15-V03**：当前截图对应当前构建；
- <a id="d15-v04"></a>**D15-V04**：任何适用失败都先处理而不是靠加权得分抵消。

### 例外

- <a id="d15-e01"></a>**D15-E01**：环境限制可以调整加载方式，但必须明确覆盖变化，例如内存载入不等于真实文件入口与原生存储复测。
